# Historically-Informed LEGO Minifigure Armor & Weapons

这是本人用于整理**历史题材兼容乐高人仔甲胄、武器与参考资料**的图片仓库。

项目目标是在现实可购买的兼容积木、人仔配件、工作室件和量产件中，结合考古、同时代图像与现代研究，寻找兼顾**历史合理性、时代/文化辨识度、零件兼容性与展示效果**的搭配方案。

## 目录

- `人仔图片_东方`：中国、东亚、内亚等题材的人仔与配件图片
- `人仔图片_西方`：欧洲、西亚等题材的人仔与配件图片
- `参考图片&资料`：考古、馆藏、壁画、现代复原及其他研究参考图片

## 说明

商品名称、人物名称和卖家宣传仅作为来源信息，不直接视为历史结论。具体判断优先参考考古实物、同时代图像、博物馆资料与可靠研究。

本仓库主要用于个人研究、整理与图片索引。部分图片来自商品页面、社交媒体、博物馆或其他公开来源，版权归原作者或权利人所有；如有不当收录，请联系删除。
